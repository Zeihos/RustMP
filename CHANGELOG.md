# История изменений

## 0.2.0-alpha.3 — 2026-11-08

- Добавлен `rustmp-transport::reliability`: ограниченный реестр подтверждений, resend по таймауту, истечение попыток, дедупликация сообщений и 32 независимых упорядоченных канала.
- Добавлены unit-тесты таймаутов, ACK-диапазонов, переполнения `u16`, дубликатов и лимитов памяти.
- Обновлена публичная документация, не смешивающая локальное состояние протокола с настоящими сетевыми кадрами.
- **Нет** интеграции с RakNet wire codec, игровым handshake и реальным GTA-клиентом.

## 0.2.0-alpha.2 — 2026-11-08

- Утверждён бренд **RUSTMP**.
- Переименованы Cargo-пакеты, зависимости, каталоги, импорты, консольная справка, стартовые скрипты и конфигурация.
- Исполняемый файл после сборки теперь называется `rustmp-server`.
- Сетевая функциональность осталась на уровне alpha.1; это обновление брендинга, а не реализация игрового протокола.
- Исправлена ошибка вывода типов в `World::query_snapshot` (Rust E0282).
- Пройдены проверки `cargo check` и `cargo test` на Ubuntu/Windows в GitHub Actions.
- Упрощена документация, добавлен `Cargo.lock` для воспроизводимых сборок.

## 0.2.0-alpha.1 — 2026-11-08

- Новый транспортный крейт (теперь `rustmp-transport`): разбор 3-байтового offline connect от legacy RakNet, 2-байтовый ответ и 5-байтовый ping/pong.
- Общий UDP-порт для query и RakNet offline.
- Ограничение количества непроверенных сессий, per-IP лимиты, 10-секундный timeout, защита от неограниченного роста таблицы IP.
- Тесты: корректные/повреждённые/повторные пакеты, ограничение слотов, таймаут, rate limit и loopback UDP.
- Тестовый клиент `offline_probe` и `test-windows.bat`.
- **Геймплей и RakNet reliability всё ещё отсутствуют.**

## 0.1.0 — 2026-11-08

- Первые крейты: query, core, server, конфигурация, пулы и тесты.
