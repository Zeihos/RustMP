# Политика безопасности RUSTMP

## Статус

RUSTMP `0.2.0-alpha.17` — исследовательский прототип. Он **не является** готовым публичным SA-MP/open.mp сервером. Настоящая игровая авторизация, надёжная защита публичного соединения, RPC и синхронизация пока отсутствуют.

| Компонент | Статус поддержки |
| --- | --- |
| Текущая ветка `main` / alpha | Принимаются сообщения об уязвимостях, исправления выполняются по возможности |
| Старые alpha-версии | Отдельные security-backports не гарантируются |
| Публичные игровые подключения | Не поддерживаются |

**Не размещайте прототип в публичном интернете и не используйте его для хранения настоящих учётных данных.** Экспериментальный `--experimental-preauth` работает только на IPv4 localhost.

## Как сообщить об уязвимости

1. При наличии в репозитории пункта GitHub **Security → Report a vulnerability** используйте приватный GitHub Security Advisory.
2. Если приватное сообщение недоступно, свяжитесь с сопровождающим через доступный **частный** канал. Не размещайте демонстрационный эксплойт, секреты или исходные PCAP в открытом Issue.
3. Укажите затронутую версию/коммит, шаги воспроизведения (на localhost), ожидаемое и фактическое поведение, а также оценку влияния. Секреты замените тестовыми значениями.

Никаких сроков ответа или выпуска исправления не гарантируется: проект разрабатывается в alpha-статусе. Сообщения рассматриваются в пределах доступных ресурсов.

## Границы защиты

Ограничение числа IP и предварительных сессий, cookie и обработка повторов — **не** полноценная DDoS-защита и **не** криптографическое подтверждение личности. Приватные диагностические дампы могут содержать данные игроков; храните их локально и удаляйте после анализа.
